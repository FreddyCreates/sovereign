## Introductio

Based on deep analysis of the SOVEREIGN organism architecture, the following 18 engines have been built and integrated. Each is named in Latin following SOVEREIGN convention, with clear functional purpose and architectural placement.

**The Complete Hierarchy:**
- **Level 0: MACHINAE (18 Engines)** — The computational cores
- **Level 1: GUBERNATORES (6 AI Managers)** — One per layer, managing 3 engines each

## I. STRATUM SOMNI — Sleep Layer Engines

These engines support the SOMNUS architecture:

### 1. CONSOLIDATOR (Consolidation Engine)
**Latin:** CONSOLIDATOR_MEMORIAE  
**Function:** Active memory consolidation during DORMIENS phase  
**Domain:** MEMORY  
**Status:** ✅ BUILT  
**Architecture:**
- Runs only during sleep phases (DORMIENS, ONEIRIC)
- Strengthens high-activity Hebbian weights
- Prunes low-activity connections toward minimum (not zero)
- Integrates fragmented memories into coherent patterns

```
consolidation_score = Σ(weight_i × activity_i) × PHI_INV × sleep_depth
```

### 2. ONEIROS (Dream Engine)
**Latin:** ONEIROS_SYNTHESIS  
**Function:** Pattern replay and creative synthesis during ONEIRIC phase  
**Domain:** INTELLIGENCE  
**Architecture:**
- Replays recent experiences in compressed form
- Recombines patterns from different domains
- Generates novel connections not made during wake
- Source of creative insights and solutions

### 3. VIGILATOR (Alertness Monitor)
**Latin:** VIGILATOR_FATIGAE  
**Function:** Tracks fatigue and triggers sleep transitions  
**Domain:** ENGINE  
**Architecture:**
- Monitors cycles since last rest
- Triggers HYPNAGOGIC phase when fatigue exceeds threshold
- Prevents "sleep debt" accumulation
- Ensures circadian compliance
