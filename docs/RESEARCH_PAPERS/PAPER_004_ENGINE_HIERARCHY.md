## Abstractum

This paper documents the complete five-level hierarchy that manages SOVEREIGN's computational engines. The architecture follows the principle: **Engines within AI within Agents within Bots, managed by Observers.** Each level manages the level below it, creating a robust chain of command that ensures no engine is ever forgotten or abandoned.

**Verba Clavis (Keywords):** engine hierarchy, AI management, autonomous agents, observer pattern, background processing, continuous operation

## VII. CYCLE ARCHITECTURE — Background Processing

The system runs multiple cycles simultaneously, invisibly to users.

### VII.1 Cycle Types

| Cycle | Latin Name | Interval | Purpose |
|-------|------------|----------|---------|
| **Cardiac** | CYCLUS_CARDIACUS | 1 beat (873ms) | Core heartbeat |
| **Respiratory** | CYCLUS_RESPIRATORIUS | Slower | Consolidation |
| **Circadian** | CYCLUS_CIRCADIANUS | 100 beats | Sleep-wake |
| **Ultradian** | CYCLUS_ULTRADIANUS | 13 beats | Mini-cycles |
| **Deep** | CYCLUS_PROFUNDUS | 233 beats | Background processing |
| **Sleep** | CYCLUS_SOMNI | Variable | SOMNUS phases |
| **Creative** | CYCLUS_CREATIVUS | Burst | Inspiration |
| **Memory** | CYCLUS_MEMORIAE | 89 beats | Consolidation |

### VII.2 Background Mode

All cycles marked `backgroundMode = true` run invisibly:
- Users logging in at 3AM see nothing different
- Processing continues regardless of user activity
- The system is **always on**, always working

### VII.3 Fatigue and Rest

- After 233 beats without rest → cognitive fatigue
- Sleep debt accumulates if fatigue > 50%
- SOMNUS phases restore the system

**"The hierarchy never breaks."**

Each level manages the level below:
- OBSERVATORES watch AUTOMATA

No engine is ever forgotten. No builder abandons their work. The hierarchy ensures continuity.
