## Development Commands

### Frontend (run from `src/frontend/`)

```bash
pnpm install --prefer-offline  # Install dependencies
pnpm typecheck                 # Type checking
pnpm fix                       # Lint fix
pnpm build                     # Build production
```

### Backend (run from `src/backend/`)

```bash
mops install       # Install Motoko packages
mops check --fix   # Type checking with auto-fix
mops build         # Build canister
```

### Integration (run from root)

```bash
pnpm bindgen  # Generate frontend bindings from backend .did
```
